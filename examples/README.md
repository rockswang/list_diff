# listdiff2 演示例程

本目录包含 `listdiff2` 模块的演示例程，用于展示模块的功能和性能优势。

## 例程说明

### 1. 简单字典列表非深度对比
**文件**: `simple_diff_demo.py`
- **数据规模**: 50万条记录
- **数据类型**: 简单字典（字符串、整数、布尔值）
- **对比模式**: 非深度对比 (`diff_obj=0`)
- **演示内容**: 大规模数据的增删改检测
- **性能重点**: 处理大量简单数据的速度

### 2. 列表首层展开比对
**文件**: `shallow_diff_demo.py`
- **数据规模**: 10万条记录
- **数据类型**: 包含列表和字典字段的复杂数据
- **对比模式**: 首层展开 (`diff_obj=1`)
- **演示内容**: 复杂数据结构的字段级变化检测
- **性能重点**: 处理中等规模复杂数据的速度

### 3. 复杂字典列表全展开对比
**文件**: `deep_diff_demo.py`
- **数据规模**: 1万条记录
- **数据类型**: 3层深度嵌套的复杂字典
- **对比模式**: 全展开 (`diff_obj=-1`)
- **演示内容**: 深度嵌套对象的精确变化定位
- **性能重点**: 处理深度嵌套数据的精度和速度

## 运行方式

### 运行单个例程
```bash
cd examples
python simple_diff_demo.py
python shallow_diff_demo.py  
python deep_diff_demo.py
```

### 运行所有例程
```bash
cd examples
python run_all_demos.py
```

## 性能预期

根据数据复杂度和规模的不同，各例程的性能表现会有所差异：

- **例程1**: 处理50万简单记录，预计在几秒内完成
- **例程2**: 处理10万复杂记录，预计在几秒内完成  
- **例程3**: 处理1万深度嵌套记录，预计在几秒内完成

## 数据生成说明

每个例程都会：
1. 生成指定规模的测试数据
2. 克隆并随机修改数据以模拟真实场景
3. 计算两个列表之间的差异
4. 输出详细的性能统计信息

这些例程展示了 `listdiff2` 模块在不同场景下的强大功能和优秀性能。
